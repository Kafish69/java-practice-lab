# Java T1 Practice Lab

A free practice site for the **KdG Applied Computer Science – Programming Fundamentals (Java)** Term 1 exam, covering modules M1–M5.

**Open it:** https://kafish69.github.io/java-practice-lab/

## Crash Course (start here)

**https://kafish69.github.io/java-practice-lab/learn.html**: learn from zero in 10 blocks: simple explanations, what to write in your notebook and how many times, memory tricks and self-checks.

## What's inside

- **Mock test** – 15 multiple choice + 8 fill in the blanks + 1 coding task, randomized every time, with a 45-minute timer and a per-module score breakdown
- **Quiz** – 63 questions ("what does this print?", "why doesn't this compile?") with instant explanations
- **Fill in the blanks** – 37 keyword and syntax questions
- **Flashcards** – 42 cards with a "still learning" pile
- **Code practice** – 19 exercises, including two old exam questions (Chess club, Student Grade Evaluator), with a checklist and model answers

Everything runs in the browser in one `index.html` file. Nothing is sent anywhere.

## Note

The code checker looks for the parts an answer needs and common mistakes. It does not run Java, so paste your code into IntelliJ to test it.

Made from the course slides, exercises and official solutions. Good luck on the exam.
